## What's new

- **Your Claude credits, right on the tile.** Tick **Show usage credits** under
  Settings → Providers → Claude.ai and the Claude tile gains a Credits line: the
  credits you purchased, plus any bonus credits from Anthropic for as long as you
  have some. It is off by default.
- **No more out-of-date numbers.** When a limit goes away (the weekly limit after a
  plan change, say) or an account stops reporting usage, the tile now clears it
  instead of leaving the last value on screen.
- **A clear message instead of an endless "Loading…".** If a provider stops sending
  usage data, or changes how it reports it, the tile now tells you so.
- **Copilot's monthly reset is on time.** It used to show an hour or two early in
  some time zones.
